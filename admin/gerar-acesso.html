Gerar seu registro de acesso

Tudo acontece neste navegador. A senha e a chave não são enviadas a lugar nenhum: a página só mostra o registro cifrado, que você manda no chat do projeto.

1. A chave do GitHub

Quem cria a chave é o organizador principal, na conta porifera-byte. Uma chave por organizador.

  1. Abra Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nome: painel- + o usuário do organizador. Validade: 1 ano (anote a data para renovar).
  3. Repository access: Only select repositories → GLCRR e GLC-privado.
  4. Permissions → Repository permissions → Contents: Read and write. Nada mais.
  5. Generate token e copie a chave (começa com github_pat_).
